# Короткая фраза для пользователя

Можно отправлять агенту так:

```text
Подключи песочницу DepSandbox (https://github.com/KORUS-Consulting-GK-LLC/DSB-start) к текущему проекту. Токен лежит в файле в корне проекта.
```

Агент должен прочитать `AGENT-INSTALL.md`, найти token-файл в корне проекта и выполнить команду из раздела `Команда для агента` в `README.md` с `-TokenFile`. Если token-файла нет или в корне несколько похожих файлов, агент должен попросить пользователя уточнить файл, не выводя содержимое токена в чат. Если текущая среда не Codex и не Cursor, агент использует штатный способ настройки MCP и правил именно для этой среды.

# Короткая фраза для пользователя

Можно отправлять агенту так:

```text
Подключи песочницу DepSandbox к текущему проекту. Запусти официальный DSB-start из GitHub, токен запроси локально в терминале, не проси вставлять токен в чат.
```

Агент должен выполнить команду из `README.md` в терминале, открытом в корне проекта. Если клиент блокирует отправку Bearer-токена из чата на внешний домен, это ожидаемое поведение безопасности: надо использовать локальный prompt `install.ps1`.

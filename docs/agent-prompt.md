# Короткая фраза для пользователя

Можно отправлять агенту так:

```text
Подключи песочницу DepSandbox к текущему проекту. Токен попроси ввести локально в терминале, в чат я его вставлять не буду.
```

Агент должен выполнить команду из раздела `Команда для агента` в `README.md`, в терминале, открытом в корне проекта. Если клиент блокирует отправку Bearer-токена из чата на внешний домен, это ожидаемое поведение безопасности: надо использовать локальный prompt `install.ps1`.

# Короткая фраза для пользователя

Можно отправлять агенту так:

```text
Подключи песочницу DepSandbox (https://github.com/KORUS-Consulting-GK-LLC/DSB-start) к текущему проекту. Токен лежит в файле в корне проекта.
```

Агент должен прочитать `AGENT-INSTALL.md`, найти token-файл в корне проекта,
сам определить фактический id текущего клиента и выполнить versioned/hash-checked
команду из раздела `Команда для агента` в `README.md` с `-Client` и
`-TokenFile`. Если token-файла нет или в корне несколько похожих файлов, агент
просит пользователя уточнить файл, не выводя содержимое токена в чат. Для
generic/ZCode агент применяет созданную карту MCP штатным способом текущей среды,
проверяет tools и удаляет одноразовый token-файл только после полного успеха.
